How editing works

  • Each email has a subject and an HTML body. Changes apply to the next email sent.
  • Insert details with placeholders like {{ '{{ name }}' }} or {{ '{{ project_url }}' }}. Each email lists the ones it can use.
  • {{ '{{ button(project_url, "See the project") }}' }} adds a big button, and {{ '{{ progress(pct) }}' }} a funding bar.
  • “Send test to me” emails you a sample, and “Reset” brings back the original.
